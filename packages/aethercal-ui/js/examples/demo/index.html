Calendario y agendamiento, de código abierto

AetherCal es un componente de calendario headless-first: un motor de geometría puro y una capa de React sobre él. Cinco vistas, arrastrar y redimensionar con reconciliación optimista, temas por tokens e internacionalización ES/EN. Se autohospeda con Docker: Postgres, API, worker y página de reservas en una sola pila, sin depender de un SaaS de terceros.

Qué incluye

  • Cinco vistas

    Mes, semana, día, agenda y cronograma con recursos: la vista adecuada para cada caso de uso.

  • Reconciliación optimista

    Arrastra o redimensiona un evento y verlo aplicarse al instante. El servidor confirma o revierte el cambio, con animación de rollback.

  • Temas por tokens

    Cuatro presets (claro, oscuro, medianoche, alto contraste) gobernados por variables CSS, sin recompilar nada.

  • i18n ES/EN

    La interfaz y el calendario cambian de idioma en vivo, sincronizando el idioma del documento.

  • Self-hosteable

    Una imagen Docker con Postgres, API, worker y página de reservas. Sin dependencia de un SaaS de terceros.

  • MIT license

    Componente y backend completos, disponibles en GitHub. Pre-alpha: la API todavía puede cambiar.

AetherCal en producción

AetherCal impulsa book.aetherlogik.com, el sistema de reservas de AetherLogik: elige franja horaria, reserva y recibe confirmación, con la misma reconciliación optimista que pruebas en la demo de abajo.
